## 3. Описание найденных багов (с указанием номеров тестов из кода)

### Баг #1: PostgreSQL таблицы не создаются (Critical)
**Описание:** При запуске SUT с PostgreSQL таблицы в базе данных не создаются автоматически.
**Факт:** Ошибка: relation "payment_entity" does not exist.
**Тест:** Не привязан к конкретному тесту (проблема окружения).

### Баг #2: Неправильное сообщение при DECLINED (Major)
**Описание:** При использовании карты 4444 4444 4444 4442 отображается уведомление "Успешно! Операция одобрена Банком".
**Ожидание:** "Ошибка! Банк отказал в проведении операции".
**Тесты:** #02 (Payment), #14 (Credit).

### Баг #3: Ошибка валидации пустого CVC (Minor)
**Описание:** При пустом поле CVC сообщение об ошибке отображается у поля "Владелец".
**Тесты:** #07 (Payment), #19 (Credit).

### Баг #4: Ошибка при CVC = 000 (Major) — НОВЫЙ
**Факт:** Ошибка "Неверно указан срок действия карты" отображается у поля "Месяц".
**Ожидание:** Ошибка должна быть у поля "CVC/CVV".
**Тесты:** **#27 (Payment)**, **#31 (Credit)**.

### Баг #5: Ошибка при цифрах в поле "Владелец" (Minor) — НОВЫЙ
**Факт:** Ошибка отображается у поля "Месяц".
**Ожидание:** Ошибка должна быть у поля "Владелец" ("Неверный формат").
**Тесты:** **#28 (Payment)**, **#32 (Credit)**.

### Баг #6: Ошибка при спецсимволах в поле "Владелец" (Minor) — НОВЫЙ
**Факт:** Ошибка отображается у поля "Месяц".
**Ожидание:** Ошибка должна быть у поля "Владелец".
**Тесты:** **#29 (Payment)**, **#33 (Credit)**.

### Баг #7: Ошибка при SQL-инъекции в поле "Владелец" (Major) — НОВЫЙ
**Факт:** Ошибка отображается у поля "Месяц".
**Ожидание:** Ошибка должна быть у поля "Владелец".
**Тесты:** **#30 (Payment)**, **#34 (Credit)**.

### Баг #8: API возвращает 500 вместо ожидаемого ответа (Major) — НОВЫЙ
**Описание:** Сервер возвращает ошибку 500 Internal Server Error при отправке запросов с пустым телом, а также при отправке валидного тела с невалидной картой.
**Тесты:** **#35**, **#36**, **#37** (все падают).

## 4. Заключение

Автоматизация выполнена на 76.3%. Были написаны новые тесты на негативные сценарии (валидация) и API. Выявлено **8 уникальных дефектов**, из-за которых падают 9 тестов. Среди багов есть критические проблемы с API (500 ошибка), неправильное отображение ошибок валидации и проблемы с БД. Все баги зафиксированы в Issues и требуют исправления разработчиками.
