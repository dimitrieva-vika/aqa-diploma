# Дипломный проект: Автоматизация тестирования веб-сервиса "Путешествие дня"

## Описание

Автотесты для веб-сервиса, предлагающего покупку тура двумя способами:
- Обычная оплата по дебетовой карте
- Выдача кредита по данным банковской карты

Сервис взаимодействует с двумя СУБД (MySQL и PostgreSQL) и эмулятором банковских сервисов (Gate Simulator).

## Технологии

- Java 11
- Gradle 8.14.5
- JUnit 5.10.2
- Selenide 6.19.1
- REST Assured 5.5.0
- Allure 2.24.0

## Запуск тестов

### 1. Подготовка окружения

1. Убедитесь, что установлены:
   - Docker и Docker Compose
   - Java 11
   - Git

2. Клонируйте репозиторий:

```bash
git clone https://github.com/dimitrieva-vika/aqa-diploma.git
cd aqa-diploma
```

3. Запустите контейнеры с MySQL, PostgreSQL и эмулятором банковских сервисов:

```bash
docker-compose up -d
```

4. Дождитесь запуска всех контейнеров (около 30 секунд). Проверить статус можно командой:

```bash
docker ps
```

### 2. Запуск SUT

#### Для MySQL (рекомендуется для тестов, так как PostgreSQL имеет баг):

```bash
java -jar aqa-shop.jar -P:jdbc.url=jdbc:mysql://localhost:3306/app -P:jdbc.user=app -P:jdbc.password=pass
```

#### Для PostgreSQL (известен баг #1: таблицы не создаются автоматически):

```bash
java -jar aqa-shop.jar -P:jdbc.url=jdbc:postgresql://localhost:5432/app -P:jdbc.user=app -P:jdbc.password=pass
```

Приложение будет доступно по адресу: http://localhost:8080

### 3. Запуск тестов

```bash
./gradlew test --info
```

### 4. Генерация Allure отчета

```bash
./gradlew allureReport
```

### 5. Просмотр Allure отчета

```bash
./gradlew allureServe
```

Отчет автоматически откроется в браузере.

## Особенности тестов

- Тесты автоматически очищают БД перед каждым запуском
- Используются валидные и невалидные данные карт из эмулятора
- Проверяется корректность сохранения данных в БД
- Проверяется корректность ответов API (REST Assured)
- Отчеты Allure с приложением скриншотов и Source Page

## Остановка окружения

Для остановки всех контейнеров:

```bash
docker-compose down
```

Для полной очистки данных БД:

```bash
docker-compose down -v
rm -rf data/
```
